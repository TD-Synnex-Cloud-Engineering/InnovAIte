# TD SYNNEX Microsoft InnovAIte Conference Archive

Public archive of materials from the TD SYNNEX and Microsoft **InnovAIte Symposium**, organized by conference year: agendas, business and technical session content, speaker information, event materials, and media.

## About InnovAIte

Microsoft InnovAIte is an annual TD SYNNEX and Microsoft partner event that helps partners grow their Microsoft practices through business strategy, technical education, and practical enablement. Recurring topics include:

- Artificial intelligence and Microsoft Copilot
- Microsoft Azure and cloud modernization
- Microsoft security
- Data and Microsoft Fabric
- Devices and AI PCs
- Microsoft partner programs, profitability, and incentives
- Partner, ISV, Microsoft, and TD SYNNEX collaboration

## File naming

Use one naming pattern so files stay searchable across years:

```text
YYYY-InnovAIte-Track-Session-DocumentType.ext
```

Examples:

```text
2027-InnovAIte-Azure-Building-a-Resilient-Cloud-Presentation.pdf
2027-InnovAIte-Azure-Arc-Workshop-Lab-Guide.pdf
2026-InnovAIte-Copilot-Session-Notes.md
2025-InnovAIte-Agenda-at-a-Glance.pdf
```

For each session, consider adding a short Markdown summary with the session title, date, track, speakers, description, related Microsoft technologies, links to the presentation and labs, and key takeaways.

## Contribution guidelines

This repository is **public**. Before adding a file:

- Confirm it is approved for public release. Do not publish confidential, NDA, partner-restricted, or customer-specific content.
- Remove personal information such as phone numbers, email addresses, hotel or registration confirmation numbers.
- Respect Microsoft, TD SYNNEX, speaker, vendor, and third-party copyright. Link to third-party material when redistribution rights are unclear.
- Publish a PDF for easy viewing and keep the editable source file (PowerPoint, Word, Excel, Markdown) when it is approved for release.
- Record the source and retrieval date for externally sourced material.
- GitHub blocks files larger than 100 MB. Link to large videos instead of uploading them.
