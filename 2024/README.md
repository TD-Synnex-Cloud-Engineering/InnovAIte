# Microsoft InnovAIte Symposium 2024

The 2024 Microsoft InnovAIte Symposium was the first InnovAIte conference hosted by TD SYNNEX and Microsoft. It brought TD SYNNEX Microsoft partners to Orlando, Florida for a business-focused program on growing their Microsoft practices, and it set the pattern for the annual InnovAIte events that followed.

## At a glance

| | |
| --- | --- |
| **Edition** | 1st annual (inaugural) |
| **Dates** | Monday, May 6 – Thursday, May 9, 2024 |
| **Venue** | Loews Portofino Bay Hotel at Universal Orlando |
| **Location** | 5601 Universal Boulevard, Orlando, Florida 32819 |
| **Hosts** | TD SYNNEX and Microsoft |
| **Audience** | TD SYNNEX Microsoft partners and customers |
| **Status** | Completed |

## Highlights

- Business-focused program with Microsoft and TD SYNNEX leaders; there were no technical sessions in 2024.
- Registration and badge pick-up opened Monday, May 6 at 2:00 p.m. in the Tuscan Foyer (lower level).
- Invited attendees received a three-night stay at the Loews Portofino Bay and all meals.
- Evening networking event at Universal Orlando.
- An episode of the TD SYNNEX *What's Surfaced* podcast was recorded live at the symposium, covering AI integration with Microsoft Surface.
