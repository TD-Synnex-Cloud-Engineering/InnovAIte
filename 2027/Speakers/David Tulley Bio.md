# David Tulley

**Solution Architect, Cloud Engineering, Enablement, TD SYNNEX**

Email: [David.Tulley@tdsynnex.com](mailto:David.Tulley@tdsynnex.com)

David Tulley is a Solution Architect on the TD SYNNEX Cloud Engineering Enablement team and the creator of CloudShift, the TD SYNNEX method for moving customers to Azure through the Cloud Solution Provider (CSP) program. He built CloudShift from the ground up into a program that now spans more than 100 partners. David has spent a decade in the Microsoft partner channel across cloud architecture, partner enablement and revenue strategy, and holds four Microsoft Azure certifications, including Azure Solutions Architect Expert and Azure Network Engineer Associate.
